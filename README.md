# Proyecto Fotaza 2

Este es el Trabajo Práctico Integrador de Programación Web II.

## Instrucciones de ejecución
1. Clonar el repositorio.
2. Instalar dependencias: `npm install`
3. Configurar el archivo `.env` (usar `.env.example` como guía).
4. Inicializar base de datos: `npm run db:init`
5. Ejecutar la aplicación: `npm start`

Acceder en: http://localhost:3000/fotazas
